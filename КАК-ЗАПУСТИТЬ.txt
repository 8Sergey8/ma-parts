MBA-parts — запуск через Terminal на Mac
========================================

Не скачивайте ZIP. Сайт обновляется и запускается командами ниже.

1) Terminal: Spotlight (Cmd + Пробел) → Terminal → Enter

2) Если ещё нет Node.js, один раз:

   brew install node

   Или установщик: https://nodejs.org (кнопка macOS).
   Нужна версия 20+. Проверка: node -v

3) ПЕРВЫЙ ЗАПУСК — скопируйте весь блок в Terminal и нажмите Enter:

cd ~
xcode-select --install 2>/dev/null || true
git clone https://github.com/8Sergey8/ma-parts.git ma-parts
cd ma-parts
chmod +x start.sh update.sh
./start.sh

Дождитесь строки Local: http://127.0.0.1:43123
Safari сам откроется, либо вставьте адрес вручную.
Окно Terminal не закрывайте.

4) КАЖДЫЙ СЛЕДУЮЩИЙ РАЗ — подтянуть сайт с GitHub и запустить:

cd ~/ma-parts
./update.sh

Только запустить, без обновления:

cd ~/ma-parts
./start.sh

5) Прайс (цены и сроки) загружается на сайте:
   http://127.0.0.1:43123/admin/ostatki
   ключ: mba-parts-local
