MBA-parts — запуск из ZIP через Terminal
========================================

Папка с сайта GitHub после третьего скачивания обычно такая:

  ~/Downloads/ma-parts-main-3

1) Spotlight (Cmd + Пробел) → Terminal → Enter

2) Один раз должен быть Node.js 20+: https://nodejs.org
   Проверка: node -v

3) Скопируйте весь блок в Terminal и нажмите Enter:

cd ~/Downloads/ma-parts-main-3
chmod +x start.sh
./start.sh

Если Terminal напишет «No such file or directory», папка называется иначе.
Тогда сначала:

cd ~/Downloads
ls -d ma-parts*

и подставьте точное имя, например ma-parts-main или ma-parts-main-2.

4) Дождитесь строки:
   Local: http://127.0.0.1:43123
Safari откроется сам или вставьте адрес вручную.
Окно Terminal не закрывайте.

5) Прайс: http://127.0.0.1:43123/admin/ostatki
   ключ: mba-parts-local
