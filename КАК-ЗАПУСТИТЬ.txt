MBA-parts — запуск на Mac
=========================

Это сайт, не приложение из App Store. Открывается через Terminal.

1) Откройте Terminal: Spotlight (Cmd + Пробел) → Terminal → Enter

2) Перейдите в папку проекта. Узнать путь: в Finder откройте ma-parts,
   правый клик по папке → Option + «Скопировать как путь», затем:

   cd "/Users/сергей/ma-parts"

   Подставьте свой путь. Если папка в Загрузках:

   cd ~/Downloads/ma-parts

3) Проверка:

   node -v
   npm -v

   Нужно v20 или выше. Если command not found:
   - установите Node.js LTS: https://nodejs.org (кнопка macOS)
   - закройте Terminal полностью (Cmd+Q) и откройте снова
   - снова выполните node -v

   Либо через Homebrew:
   brew install node

4) Запуск (первый раз 1–2 минуты):

   npm install
   npx --yes next dev --hostname 127.0.0.1 --port 43123

5) Когда появится:
   Local: http://127.0.0.1:43123
   откройте этот адрес в Safari или Chrome.
   Окно Terminal НЕ закрывайте.

Или одной командой из папки проекта:

   chmod +x start.sh
   ./start.sh
