MBA-parts — как открыть сайт на компьютере (Windows)
====================================================

Это не программа-установщик. Сайт запускается из папки ma-parts.

1) Распакуйте архив, если скачали ZIP. Не запускайте start.bat изнутри ZIP.

2) Win + R → вставьте:
   cmd
   Enter

3) В чёрном окне вставьте СВОЙ путь к папке (пример):

   cd /d C:\Users\Сергей\ma-parts

   Узнать путь: в Проводнике откройте папку ma-parts, кликните
   в адресной строке, скопируйте путь.

4) Проверка Node.js:

   node -v
   npm -v

   Нужно v20 или выше. Если «не является внутренней командой»:
   - поставьте Node.js LTS: https://nodejs.org
   - галочка Add to PATH
   - ПЕРЕЗАГРУЗИТЕ компьютер
   - снова откройте cmd и повторите node -v

5) Установка и запуск (один раз подождать 1–2 минуты):

   npm install
   npx --yes next dev --hostname 127.0.0.1 --port 43123

6) Когда появится строка вроде:
   Local: http://127.0.0.1:43123
   откройте в Chrome/Edge именно этот адрес.
   Чёрное окно НЕ закрывайте.

Если окно сразу закрылось — снова запустите start.bat.
Рядом появится файл start-log.txt, там будет ошибка.
